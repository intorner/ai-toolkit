# 初始化驗證清單

> 版本：v0.5
> 更新日期：2026-09-18

初始化/retrofit完成後，用本清單驗證 repository bootstrap，不把 runtime/tool binding當初始化完成條件。

## Authority

- [ ] `current-state.md` 是目前有效 Current Truth / resume surface
- [ ] `CLAUDE.md` 是 bootstrap/control entrypoint，不宣稱自己是單一真相來源
- [ ] Method / Spec / runbook / evidence各自保持正式 authority
- [ ] chat/memory只作 reference
- [ ] local working copy / host path / Vault path / model / tool binding沒有被寫成永久 authority

## Project files

- [ ] `README.md` 存在或有合理例外
- [ ] `CLAUDE.md` 存在
- [ ] `current-state.md` 存在
- [ ] `handoff.md`、`worklog.md`、`runbook.md`、`tasks.md`依長期接續需要存在
- [ ] `.gitignore` 排除 `.claude/`、`.codex/`、`.env`、credentials、cache/build/output等不應入版控內容
- [ ] `.gitattributes` 有需要的跨平台文字行為
- [ ] 沒有為形式預建無用 empty future-facing directories

## CLAUDE.md

- [ ] 有 Project identity / purpose / scope
- [ ] 有 Current Truth pointer
- [ ] 有 authority precedence
- [ ] 有 startup / progressive disclosure 規則
- [ ] 若使用 shared AI engineering，只有 thin `codex-sync` redirect
- [ ] 若涉及 GB10，redirect到 canonical GB10 bootstrap/routing，而不是複製 RDC/Codex/Hermes細則
- [ ] 沒有硬編碼 permanent Codex/Hermes/RDC/host/runner/model route
- [ ] 有 Human authorization boundary
- [ ] 有 Do Not Reopen / no reassurance rebuild invariant（長期 AI engineering Project適用）

## Current state / durable recording

- [ ] `current-state.md` 只保留目前有效 Current Truth
- [ ] superseded state沒有與新 state並列成 active-looking truth
- [ ] 必要 history移到 worklog/checkpoint/history surface
- [ ] handoff只在 phase/ownership/unresolved continuation需要時保存 substantive context
- [ ] checkpoint不取代 Method/Spec/Current Truth

## Shared capability routing

- [ ] consumer不靠列舉全部 capability 才能工作；shared routing externalized
- [ ] shared routing / Skill / workflow / authorization / transport authority在 `codex-sync`
- [ ] consumer repo只保存 project-specific invariant + canonical pointer
- [ ] local tool visibility / connector visibility不被當成 destination/route authority

## Optional projections

- [ ] Obsidian/work note若存在，只作 operational projection
- [ ] 缺 Obsidian/work note不會阻斷初始化
- [ ] Windows/Linux/NAS path若存在，標示為 local projection / example
- [ ] 沒有把 drive letter / absolute path當跨設備 canonical locator

## Git / GitHub authorization

- [ ] read-only repository inspection與Git mutation有分離
- [ ] `git init/add/commit` 若已執行，有明確 Human write authorization
- [ ] remote create/change/push若已執行，有明確 Human remote-write authorization
- [ ] 初始化 request本身沒有被當作 commit/push authorization
- [ ] existing dirty working tree未被 reset/checkout/覆寫

## ChatGPT Project Instructions boundary

- [ ] ChatGPT Project Instructions不由 ai-toolkit模板自行發明
- [ ] 如需產生/刷新 Project Instructions，使用 `codex-sync/docs/chatgpt-project-bootstrap-library.md`
- [ ] Repository `CLAUDE.md` 與 ChatGPT Project Instructions分工清楚、沒有第二份 shared routing authority

## Existing Project retrofit

- [ ] 先做 read-only audit與 NO_CHANGE / THIN_REFRESH_REQUIRED / LEGACY_MODERNIZATION_REQUIRED 分類
- [ ] 只修 authority/bootstrap/routing gap
- [ ] 不為 modernization重做已 CLOSED/PASS/OPERATIONAL capability
- [ ] 不改 domain truth / functional implementation，除非另有授權與直接需求

## Completion

必要項目 PASS後才宣告 initialization/retrofit完成；若有未決 authorization、authority ambiguity或 consumer routing gap，fail visible，不用額外 Router/daemon/service補洞。
