# 專案初始化模板

> 版本：v0.7
> 更新日期：2026-09-18
> 適用：新 Project repository bootstrap、既有 Project retrofit

本模板只建立 Project repository/state 基礎。ChatGPT Project Instructions 由 `codex-sync/docs/chatgpt-project-bootstrap-library.md` 負責；shared routing不在本模板複製。

## Core invariants

- `current-state.md` = Current Truth / active resume surface。
- `CLAUDE.md` = bootstrap/control entrypoint，不是單一真相來源。
- shared AI engineering / GB10 routing externalized to `codex-sync`。
- local path / Obsidian / host / model / tool binding = projection only。
- Human authorization是 authority，不是 transport。
- Git/remote write需獨立明確授權。
- 不預建空的 future-facing directories。
- Durable checkpoint只在 material decision/history真的需要時建立。

## Minimum structure

```text
README.md
CLAUDE.md
current-state.md
handoff.md
worklog.md
runbook.md
tasks.md
.gitignore
.gitattributes
```

`docs/`、`scripts/`、`tools/`等只在 current Project實際需要時建立。

## CLAUDE.md template

```markdown
# <Project Name>

## Project identity
- Project code: `<code>`
- Repository authority: `<owner/repo 或 local-only>`
- Current Truth: `current-state.md`
- Shared AI engineering authority: `codex-sync`（若適用）

## Purpose / Scope
- <purpose>
- <in scope>
- <out of scope>

## Authority
1. Project `current-state.md` / accepted Method / Spec
2. Human accepted decisions / evidence
3. `codex-sync` shared bootstrap/routing（若適用）
4. local/managed projections
5. chat/memory reference only

## Startup
1. Read `CLAUDE.md`.
2. Read `current-state.md`; judge sufficiency/freshness.
3. Read only directly relevant downstream docs.
4. Use existing-capability discovery for shared work.
5. Do not reopen CLOSED/PASS/OPERATIONAL capability plumbing for reassurance.

## Shared Capability Redirect
- Shared capability routing stays in `codex-sync`.
- Do not hard-code Codex/Hermes/RDC/host/runner/model as permanent primary.
- If GB10 is involved, follow `codex-sync/docs/gb10-gpt-bootstrap.md` and canonical routing.

## Authorization
Repository/Git write, remote write/push, deployment, service/runtime, model/backend, package install, destructive filesystem, network/security, credential/secret and privilege changes require explicit Human authorization.

## Optional projections
- Local work root: `<optional>`
- Work note: `<optional semantic locator>`
- Platform notes: `<optional>`
```

## State templates

### current-state.md

```markdown
# <Project Name> Current State

- status:
- current_goal:
- last_completed:
- blockers:
- next_step:
- authoritative_pointers:
```

只保留仍有效 Current Truth；superseded history移到 worklog/checkpoint/history surface。

### handoff.md

只有 phase change / owner transfer / unresolved continuation需要時才填 substantive handoff；不要每次 session都當 log。

```markdown
# <Project Name> Handoff

## Current objective
## Completed / accepted
## Unresolved
## Authoritative pointers
## Exact next action
```

### worklog.md

```markdown
# <Project Name> Worklog

| Date | Summary | Evidence/commit |
|---|---|---|
```

### tasks.md

```markdown
# <Project Name> Tasks

## Next
- [ ] <task>

## Decisions
## Blockers
```

### runbook.md

```markdown
# <Project Name> Runbook

## Start
## Validate/Test
## Operate/Deploy
## Platform notes
```

## Optional work-note projection

若 Project確實使用 Obsidian，可建立：

`專案庫/<project-code>/工作筆記.md`

但它是 operational projection，不是初始化完成的必要條件，也不得覆蓋 repository Current Truth。

## Git / GitHub

Project file creation與 Git mutation分離。

初始化 request本身只授權建立/修改初始化檔案，不自動授權：

- `git init`
- `git add`
- commit
- remote create/change
- push
- GitHub repo create

只有 Human 明確授權對應 scope後才執行。若已授權，可依 current platform/runbook使用適當 Git tooling；模板不固定 `gh repo create --push` 為必經步驟。

## Existing Project retrofit

1. Read existing `CLAUDE.md`, `current-state.md`, repo state and relevant durable notes.
2. Preserve accepted domain truth and existing user changes.
3. Add/patch only bootstrap/state/governance gaps.
4. Do not overwrite functional code or implementation merely to match template.
5. Replace legacy authority statements only when a newer canonical rule clearly supersedes them.
6. Git/remote mutations remain separately authorized.

## Validation

完成後依 `初始化驗證清單.md`，至少確認：
- `current-state.md` 是 Current Truth surface。
- `CLAUDE.md` 是 bootstrap/control entrypoint。
- shared routing externalized。
- local paths/tool bindings not treated as permanent authority。
- side-effect authorization boundary preserved。
- no unnecessary empty structure created。
